# Aulas FPP — Prof. Wilton Gomes

Site estático (GitHub Pages) com as aulas interativas e materiais.

- `risco-sca/` — Estratificação de risco da dor torácica na emergência (8º período)
  - `aula.html` — slides. Ao vivo: `aula.html?ao-vivo&sala=<id>` liga a votação por QR Code (Firebase Realtime Database, projeto `aulas-fpp-wilton`).
  - `votar.html?s=<sala>&c=<caso>` — página de voto do aluno · `praticar.html` · `quiz.html` · `resumo.pdf` (gerado de `resumo.html`)
- `contato/` — cartão virtual + `wilton-gomes.vcf`
- `assets/` — identidade FPP (Montserrat, logos), `votos.js` (voto via REST), `qrcode.js` (MIT, Kazuhiko Arase)
